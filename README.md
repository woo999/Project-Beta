# Project Beta — 臺股個股波段研究

獨立於 Project Alpha 的研究專案。本專案只做策略研究、歷史回測與紙上追蹤；**不連接券商、不融資、不槓桿、不實際下單**。

## 範圍

- 股票池：0050（元大台灣 50 ETF）與 FTSE TWSE Taiwan Mid-Cap 100 的歷史成分股。
- 持有期間：數週至 3 個月。
- 組合上限：同時最多 5 檔。
- 優先策略：
  1. 強勢股突破後回踩不破。
  2. 趨勢動能。
- 輸出：僅產生「研究候選」；在樣本外驗證、成本敏感度測試及紙上追蹤通過前，不產生買進指令。

## 研究守則

1. 使用每個交易日當時可知的成分股與資料；禁止用現行成分股回填歷史。
2. 所有訊號最早於下一個可交易時點成交；不以收盤後才知道的資料在同日成交。
3. 回測一律納入雙邊交易成本、滑價、停牌／漲跌停無法成交與除權息價格處理假設。
4. 先做樣本內探索，再做時間切分的樣本外驗證；參數不得以樣本外績效回頭調整。
5. 除年化報酬外，必報最大回撤、勝率、盈虧比、持有天數、換手率、交易數、成本後績效與基準比較。

## 資料來源

只採免費且可追溯的官方來源。候選來源與抓取方式列在 `docs/data_sources.md`；未確認可取得歷史成分清單前，不開始宣稱回測結果。
