# 免費官方資料來源與驗證狀態

| 資料 | 預定官方來源 | 用途 | 狀態 |
|---|---|---|---|
| 上市日線 OHLCV | 臺灣證券交易所（TWSE）市場資訊／日交易資訊 | 0050、上市股票價格與成交量 | 待驗證下載介面與歷史覆蓋 |
| 上櫃日線 OHLCV（若歷史成分涵蓋） | 證券櫃檯買賣中心（TPEx）交易資訊 | 中型100股票價格與成交量 | 待驗證 |
| 台灣50指數歷史資料 | TWSE FTSE TWSE Taiwan 50 Index Historical Data | 基準與資料交叉驗證 | 已確認公開歷史頁面 |
| 中型100指數歷史資料 | TWSE FTSE TWSE Taiwan Mid-Cap 100 Index Historical Data | 基準與資料交叉驗證 | 已確認公開歷史頁面 |
| 歷史成分與生效日 | FTSE Russell／TWSE 指數審核公告、成分股異動檔 | Point-in-time 股票池 | **未通過：尚未取得逐期完整清單；見 `research_log/2026-07-28_data_audit.md`** |
| 證交稅、手續費規則 | 財政部／TWSE／券商公開費率文件 | 成本假設版本化 | 待確認採用日期與計算規則 |

> 禁止以目前 0050 或中型100成分股取代歷史成分股。若官方歷史成分資料不連續，該期間不納入正式回測，並在報告中明確標示缺口。

## 初版成本情境

回測至少呈現三組情境：低／基準／保守。每組的手續費折扣、證交稅、滑價與交易價格規則均須由官方規則或可重現設定支持；在資料驗證前不得填入漂亮但未證實的數字。
