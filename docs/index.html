長短結構判讀
長期位置＝1年×20%＋120日×30%＋60日×50%的加權名次，越近期權重越高。加權≤5.5且60日≤6＝長期強勢；加權≥11.5且60日≥11＝長期弱勢；其餘＝長期中性。
長期趨勢＝比較1年與60日：60日比1年至少前進4名＝長線轉強；退後4名＝長線轉弱；其餘＝長線穩定。
短期位置＝20日×20%＋10日×30%＋5日×50%的加權名次。≤5.5＝短期強勢區；≥11.5＝短期弱勢區；其餘＝短期中位。
短期速度＝20日→10日→5日。淨前進≥6且兩段都前進＝短期急升；淨前進≥3＝短期升溫；淨退後≥6且兩段都退＝短期急退；淨退後≥3＝短期退潮。兩段方向相反且波動明顯＝短期震盪；其餘＝短期整理。
最後把長期位置、長期趨勢、短期位置、短期速度一起合成「主流續強／主流高檔／強勢退潮／短線強勢／弱勢反彈／弱勢續弱…」。這是市場結構描述，不是進出場指令。
